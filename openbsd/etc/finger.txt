Kyriakon.net

Secure email, static web hosting, and pass repositories. Principled hosting,
run by Orthodox Christians.

Mail held in a form the platform cannot read, sites you can read over HTTPS or
gemini, and pass-compatible git repositories. One box, configuration published
so anyone can audit it, and no JavaScript anywhere in the stack.

Nobody here has a shell. The standard account is a shell-less user, which is the
design rather than a limit applied on top of it.

    https://kyriakon.net

Audit us. Every non-secret piece of infrastructure config is published:

    https://github.com/kyriakon/kyriakon-infra

Contact: hello@kyriakon.net
